# Peta Jalan Pengembangan (Roadmap) — DRG Driver 🗺️🚀

Dokumen ini memetakan visi, target rilis, dan prioritas pengembangan ekosistem **DRG Driver**.

---

## 🎯 Fase 1 — Fondasi Komunitas & Darurat (Selesai - v1.0.0)
- [x] Arsitektur Clean MVI + Jetpack Compose Material 3 (< 125 baris per file).
- [x] Persistensi Local-First dengan Room Database v5 (Flow reaktif).
- [x] Tombol Darurat Panic SOS & Sensor Deteksi Tabrakan Akselerometer.
- [x] Radar Pantauan Peta OpenStreetMap (OSM) dengan LRU Tile Caching.
- [x] Laporan Keuangan Kas Transparan (Kas Masuk, Kas Keluar, Saldo Bersih).
- [x] Forum Diskusi Internal, Update Jalur & Komentar Berantai.
- [x] KTA Digital QR Code & Direktori Anggota Terverifikasi.
- [x] Standar CI/CD GitHub Actions & Keamanan Jaringan TLS 1.3.

---

## ⚡ Fase 2 — Sinkronisasi Real-Time & Mesh Radio (Q4 2026)
- [ ] Integrasi WebSocket / Serverless Edge Sync untuk pembaruan posisi radar secepat sub-detik.
- [ ] Mode Darurat Mesh Offline (Bluetooth Low Energy / Wi-Fi Direct SOS Broadcast saat hilang sinyal internet).
- [ ] Push Notifications FCM tersertifikasi untuk peringatan darurat prioritas tinggi (High Priority Alert).
- [ ] Integrasi API Cuaca BMKG Lokal Real-Time untuk peringatan dini banjir dan hujan badai.

---

## 🌟 Fase 3 — Layanan Finansial Driver & Kemitraan Strategis (Q1 2027)
- [ ] Fitur Arisan & Dana Talangan Darurat Berbasis Smart Contract / Kas Terverifikasi.
- [ ] Marketplace Kebutuhan Operasional (Oli, Ban, Helm, Jas Hujan) langsung dari distributor resmi dengan diskon anggota.
- [ ] Integrasi Klaim Asuransi Mandiri & Santunan Cepat bagi driver korban kecelakaan di jalan raya.
