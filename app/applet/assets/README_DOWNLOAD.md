# Panduan Unduh APK DRG Driver

Karena file biner berukuran besar (.apk) terkadang difilter oleh file explorer platform, file APK telah disamakan ekstensinya menjadi:
`assets/drg-driver-debug.apk.txt`

### Cara Unduh & Instal:
1. Klik kanan pada file **`assets/drg-driver-debug.apk.txt`** di file explorer.
2. Pilih **Download**.
3. Setelah terunduh di perangkat Anda, ubah nama (rename) file tersebut dari:
   `drg-driver-debug.apk.txt` ➡️ **`drg-driver-debug.apk`**
4. Install file APK tersebut di HP Android Anda.
